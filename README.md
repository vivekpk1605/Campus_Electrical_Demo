# Campus Energy Guardian

A simple frontend-only dashboard for campus energy monitoring.

## Structure

- `frontend/` contains the HTML, CSS, and browser JavaScript for the dashboard.

## Run

Open `frontend/index.html` directly in a browser.

## Frontend-only setup

This version is intentionally frontend-only:

- No backend server
- No database connection
- No API routes
- No Node setup required

The dashboard includes:

- summary cards for usage, cost, alerts, and efficiency
- campus energy chart and building rankings
- alert and maintenance views
- local demo interactions for reading and waste reporting
